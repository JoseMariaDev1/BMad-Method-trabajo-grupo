# Nébula

Dashboard de cuidado de kachimbas migrado a Angular standalone.

## Requisitos

- Node.js 20.19 o superior
- npm

## Desarrollo

```bash
npm install
npm start
```

La aplicación estará disponible en `http://localhost:4200`.

## Compilación de producción

```bash
npm run build
```

El CSS original se mantiene como hoja global en `styles.css`.
